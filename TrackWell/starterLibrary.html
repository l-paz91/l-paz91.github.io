TrackWell Starter Library

Small library of foods to get you started with TrackWell.

Starter Library · Last updated: August 2026

What is this? This is a small library of foods that I've been using to test TrackWell. It contains a variety of common foods, including some fast food items, to help you get started with the app. You can import this library into TrackWell to have a starting point for your tracking.

Important Notes

Any of the foods in the library are not an endorsement of the product or brand. They are simply what was available as I ate them. I am also Coeliac (gluten-intolerant), so a lot of the items in the library are gluten-free. I live in the UK, so some of these foods might not be available in other countries or have different nutritional information.

Nutritional Accuracy

The nutritional information for the foods in this library is based on my personal experience and research. However, please note that the information may not be completely accurate or up-to-date. Always verify the nutritional information with the manufacturer or a reliable source.

How to Import

Save this zip file to an online storage service (e.g., Google Drive, OneDrive). In the app drawer, tap the "Import Foods Only" option and select the zip file.
